# Brand assets

| File | Use |
|---|---|
| `logo.png` | 512 x 512 logo used in the README (compressed, about 127 KB) |
| `social-preview.png` | 1280 x 640 GitHub social preview card (about 112 KB, under GitHub's 1 MB limit) |

## Setting the GitHub social preview

GitHub does not read this from the repository. After pushing, go to the repository on GitHub:
Settings, General, Social preview, Edit, Upload an image, and choose `docs/assets/social-preview.png`.
